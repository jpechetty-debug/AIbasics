### Question 1 (Python)
**Which Python library is most commonly used for making web API requests (e.g., to a weather or news service)?**

A) `turtle`
B) `requests`
C) `socket`
D) `flask`

**Correct Answer:** B

**Feedback:**
- **B) ✓ Correct!** The `requests` library is the standard for calling web APIs.

---

### Question 2 (Spreadsheets)
**When asking AI to write a spreadsheet formula for conditional totals, what should you specify?**

A) Nothing, just say "add a formula."
B) The exact condition and columns involved (e.g., "sum column B where column A equals 'Groceries'").
C) The color of the cells.
D) Nothing matters, AI guesses correctly every time.

**Correct Answer:** B

**Feedback:**
- **B) ✓ Correct!** Being specific about the condition and columns ensures the formula actually matches your intent.

---

### Question 3 (Regex)
**You need to match an email address. Is it better to write the regex from scratch or ask AI?**

A) From scratch, always.
B) AI, because email regex is notoriously complex and well-known patterns already exist.
C) Neither, this can't be done with regex.
D) Use a random guess.

**Correct Answer:** B

**Feedback:**
- **B) ✓ Correct!** Standard patterns (email, phone number, URL) are perfect candidates for AI generation.

D) They are only useful for professional teams.

**Feedback:**
- **A) ✓ Correct!** Clear documentation gives both you and any AI assistant helpful context for future changes.

### Question 6 (Workflow)
**What is the "Critic" step in Code Generation?**

A) Telling the AI it did badly.
B) Asking the AI (or reviewing yourself) to check the generated code for bugs or issues before running it.
C) Deleting the code.
D) Sharing it immediately with no review.

**Feedback:**
- **B) ✓ Correct!** Audit before you run it, especially if it touches real data.

### Question 7 (Security)

B) It's now less secure, and you should ask why and whether it's really necessary.

### Question 10 (Debugging)

### Question 11 (Refactoring)
**"Refactoring" code usually means:**

A) Changing what it does entirely.
B) Cleaning up the internal structure without changing the external behavior (e.g., adding comments, simplifying logic).
C) Deleting it.

**Feedback:**
- **B) ✓ Correct!** It's about improving quality and readability, not changing the outcome.

### Question 13 (Security)
