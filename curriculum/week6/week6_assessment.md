### Question 1 (Concepts)
**What is the primary benefit of "Low-Code" AI for a Network Admin?**

A) It requires deep Java knowledge.  
B) It allows building tools (Chatbots/Search) visually without writing full application code.  
C) It is slower.  
D) It is only for games.  

**Correct Answer:** B

**Feedback:**
- **B) ✓ Correct!** Rapid tool creation.

---

### Question 2 (RAG)
**RAG solves which major LLM limitation?**

A) Lack of logic.  
B) Lack of access to private/recent data (Context Cutoff).  
C) Speed.  
D) Cost.  

**Correct Answer:** B

**Feedback:**
- **B) ✓ Correct!** It bridges the gap between the model and your data.

---

### Question 3 (Configuration)

A) Define the Persona, Tone, and Rules.  
B) Log the user in.  
C) Store the data.

**Correct Answer:** A

**Feedback:**
- **A) ✓ Correct!** It is the "Soul" of the bot.

### Question 4 (Vector DB)

A) Keywords.  
B) Mathematical Embeddings (Numbers) representing meaning.  
C) Images.  
D) Audio.  

**Correct Answer:** B

**Feedback:**
- **B) ✓ Correct!** This enables semantic search ("King" ~ "Queen").

### Question 5 (Chunking)
**When preparing a PDF for RAG, "Chunking" means:**

**Correct Answer:** B

**Feedback:**
- **B) ✓ Correct!** LLMs ingest chunks, not whole libraries at once.
