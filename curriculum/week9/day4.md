# 20+ AI Solutions for Your Daily Workflow

Welcome to the **AI Solutions Catalog**. Today is designed as a rapid-fire exploration of practical, ready-to-use AI workflows that solve common problems in IT and business operations.

## 🛠️ The Catalog Categories

We have grouped these solutions into four main areas: **Content & Policy**, **Analysis & Logic**, **Operations & Support**, and **Creative & Future**.

---

### 📂 1. Content & Policy Solutions
1.  **The Policy Simplified**: "Convert this 20-page security policy into a 1-page 'Quick Reference' for developers."
2.  **The Legal Translator**: "Highlight any 'Red Flags' in this SaaS End User License Agreement (EULA)."
3.  **The Resume/JD Matcher**: "Compare this candidate's resume against our Senior Network Engineer job description and score the match 1-10."
4.  **The Knowledge Base Generator**: "Turn this Slack thread about fixing the VPN into a structured KB article."
5.  **The Brand Voice Checker**: "Ensure this technical blog post follows our corporate branding and tone guidelines."

### 📈 2. Analysis & Logic Solutions
6.  **The Budget Trend Analyzer**: "Look at our AWS spend over the last 3 months and identify the top 3 areas for potential cost-saving."
7.  **The SQL Optimizer**: "Rewrite this slow SQL query to be more efficient and explain the changes."
8.  **The Logic Checker**: "I'm planning this network migration step. Find any 'Single Points of Failure' in my logic."
9.  **The Data Formatter**: "Clean this messy CSV list of MAC addresses and ensure they all use the `XX:XX:XX:XX:XX:XX` format."
10. **The Regex Builder**: "Create a regular expression that matches valid IPv6 addresses."

### ⚙️ 3. Operations & Support Solutions
11. **The Ticket Triager**: "Categorize these 50 helpdesk tickets into 'Hardware,' 'Software,' 'Network,' or 'Account' issues."
12. **The Root Cause Generator**: "Based on these syslog errors, generate a draft post-mortem report."
13. **The Shell Script Documenter**: "Add meaningful comments to this legacy bash script so a junior admin can understand it."
14. **The CLI Cheat Sheet**: "Generate a 'Top 10' list of useful `kubectl` commands for debugging pod issues."
15. **The API Mock Generator**: "Create a JSON mock response for this specific API endpoint schema."

### 🎨 4. Creative & Future Solutions
16. **The Presentation Outliner**: "Create a 10-slide outline for a presentation on 'The Benefits of Moving to SD-WAN'."
17. **The FAQ Generator**: "Based on our new project proposal, what are the top 5 questions a skeptical manager might ask?"
18. **The Social Post Drafter**: "Write 3 LinkedIn posts announcing our team's successful migration to the cloud."
19. **The Onboarding Guide**: "Create a 5-day onboarding schedule for a new IT intern joining our team."
20. **The Meeting Facilitator**: "Suggest 5 'Icebreaker' questions for our upcoming remote team-building session."

## 🚀 Practical Exercise: Pick & Build

Your task today is to browse this catalog and choose **one** solution from each category (total of 4).
For each solution, you must:
1.  Write the **System Prompt** (the Persona).
2.  Write the **User Prompt** (the Task).
3.  Test it with sample data.
4.  Refine it once using the "Critic Pattern" we learned in Week 4.
